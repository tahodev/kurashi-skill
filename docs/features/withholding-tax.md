# withholding-tax ガイド

月給から天引きされる源泉所得税(月額表の甲欄)の目安を、国税庁が公表する電算機計算の特例の式で計算するスキル。外部APIは使わない。

**正本は [`withholding-tax/SKILL.md`](../../withholding-tax/SKILL.md)。** 計算式、公式の計算例、税額表の抜粋、実測で確認した罠、失敗時の対応はすべてそちらを参照。

- データ: 国税庁 令和8年分・令和9年分の源泉徴収税額表と電算機計算の特例(2026-10-03確認)
- できること: 社会保険料等控除後の月給と扶養人数から税額を計算。令和8年分と令和9年分の切り替え
- ヘルパー: `lookup.py`(外部パッケージ不要)。公式の計算例4件をテストで再現
- 注意: 式の結果は税額表と一致しないことがある(年末調整で精算)、令和9年分の税額表は公開済みだが2027年以降の支給分用、乙欄・賞与・日額表は対象外
