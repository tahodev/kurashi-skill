# garbage-day ガイド

5374(ゴミナシ)形式の公開CSVと自治体公式のオープンデータで、ごみの収集日と品目別の分別・出し方を調べるスキル。APIキー不要。

**正本は [`garbage-day/SKILL.md`](../../garbage-day/SKILL.md)。** 曜日書式(`月 木` / `月1`)の読み方、target.csv の列構成、対応自治体マトリクス、対象外自治体での対応はすべてそちらを参照。

- 収集日: 各地の5374リポジトリの `data/area_days.csv`(金沢・美唄・松前・笠間・上砂川を実測。大分市版は金沢データのコピー状態のため使わない)
- 品目別: 5374の `data/target.csv` に加え、多摩市(品目別索引CSV)・横浜市(出し方一覧表CSV、CP932)の公式オープンデータを2026-09-19に実測登録
- ひとことメモ: 乾電池・スプレー缶の区分は自治体でまったく違う(横浜はスプレー缶の穴あけ不要)。類推で答えず、必ずその自治体のデータで確認
- 対象自治体がなければ推測せず、自治体公式の収集カレンダー・分別辞典を案内する
