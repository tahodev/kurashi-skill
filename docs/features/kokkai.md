# kokkai ガイド

国会会議録検索システムの公式APIで国会議事録(1947年の第1回国会〜)を検索するスキル。APIキー・ログイン不要。

**正本は [`kokkai/SKILL.md`](../../kokkai/SKILL.md)。** エンドポイント、引数、実測で確認した罠、失敗時の対応はすべてそちらを参照。

- データ: 国会会議録検索システム API(衆参の全会議録・全発言)
- できること: 発言本文キーワード検索(AND)、発言者(部分一致)、会議名(OR)、院・開催日・回国数での絞り込み。発言単位/会議単位(全発言つき)/会議一覧の3モード
- ヘルパー: `lookup.py` がJSONをパースして返す(外部パッケージ不要、recordPacking=json自動付与)
- 注意: モードごとの最大件数(100/10/100)、既定はXML、anyとnameOfMeetingでスペースの意味が逆、収録は約1か月ラグ(2026-10-01実測で最新2026-08-26)
