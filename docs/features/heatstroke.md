# heatstroke ガイド

環境省 熱中症予防情報サイトの公式API v1で暑さ指数(WBGT)の予測値・実況値を読むスキル。APIキー・ログイン不要。

**正本は [`heatstroke/SKILL.md`](../../heatstroke/SKILL.md)。** エンドポイント、引数、5段階区分、失敗時の対応はすべてそちらを参照。

- データ: 環境省 熱中症予防情報サイト API v1(全国865の情報提供地点)
- できること: 最寄り地点の暑さ指数予測(3時間ごと・約57時間先)、実況値(推定/実測・時間単位)、地点検索(名称/緯度経度)
- ヘルパー: `lookup.py` が地点マスタをキャッシュし、最寄り地点の予測を5段階区分つきで表示
- 注意: 旧CSVサービスは終了(API v1のみ)、`pref_cds` はJISコードではない、値は地点名と基準時刻つきで伝える。サービス期間は概ね4月下旬〜10月
