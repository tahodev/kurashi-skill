# koyobun-check ガイド

文化審議会建議「公用文作成の考え方」(令和4年)を根拠に、公的文書・ビジネス文書の日本語表記を校閲するスキル。ネットワーク不要。

**正本は [`koyobun-check/SKILL.md`](../../koyobun-check/SKILL.md)。** チェックリスト全項目、文書分類による厳しさの違い、指摘の出し方はすべてそちらを参照。

- 根拠: 建議「公用文作成の考え方」(付)解説(文化庁PDF)
- ひとことメモ: まず文書を「法令/告示・通知/記録・公開資料/解説・広報」に分類する。分類で許容が変わる
- 指摘は「修正必須」と「検討」を分け、根拠の箇条(例: Ⅰ-4ア)を添える
