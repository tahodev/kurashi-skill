# egov-laws ガイド

e-Gov法令API v2(デジタル庁)で日本の現行法令の条文を引くスキル。APIキー・ログイン不要。結果は条文そのもので、法的助言ではない。

**正本は [`egov-laws/SKILL.md`](../../egov-laws/SKILL.md)。** エンドポイント、引数、実測で確認した罠、失敗時の対応はすべてそちらを参照。

- データ: e-Gov法令検索の法令データ(2026-10-02実測で9,572法令)
- できること: 法令名検索、条番号指定の条文取得(枝番つき)、時点指定(2017-04-01以降)、改正履歴(未施行を含む)、条文本文の全文検索
- ヘルパー: `lookup.py`(外部パッケージ不要)。条番号はNum属性で探すので、`elm=Article[N]` の罠を踏まない
- 注意: `elm=Article[N]` はN番目の要素で第N条ではない(民法で`Article[709]`は第643条)、`asof`は2017-04-01以降のみ、有効な法令でも`PreviousEnforced`になることがある、メンテナンス中はHTMLが返る
