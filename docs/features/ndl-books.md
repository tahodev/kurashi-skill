# ndl-books ガイド

国立国会図書館サーチの公式API(OpenSearch / SRU)で書誌を検索するスキル。APIキー・ログイン不要。

**正本は [`ndl-books/SKILL.md`](../../ndl-books/SKILL.md)。** エンドポイント、引数、実測で確認した罠、失敗時の対応はすべてそちらを参照。

- データ: 国立国会図書館サーチ API(日本のほぼ全刊行物の書誌)
- できること: ISBN照会、タイトル検索(部分一致)、著者名検索、任意キーワード(AND)検索。タイトル(読み)・著者・出版社・刊行年・資料種別(紙/電子)・書誌IDを返す
- ヘルパー: `lookup.py` が検索結果のXMLをパースしてJSONで返す(外部パッケージ不要)
- 注意: タイトルは部分一致(`雪国`で7,719件、2026-09-29実測)、1つのISBNに複数レコード、ページング既定200件、旧ホストiss.ndl.go.jpは303リダイレクト。蔵書・貸出はcalil-books
