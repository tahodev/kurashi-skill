# address-normalize ガイド

デジタル庁 アドレス・ベース・レジストリ(ABR)の公開マスタで住所文字列を都道府県・市区町村・町字に分解・正規化するスキル。APIキー・ログイン不要(CC BY 4.0)。

**正本は [`address-normalize/SKILL.md`](../../address-normalize/SKILL.md)。** マスタの構造、表記ゆれの実例、失敗時の対応はすべてそちらを参照。

- データ: デジタル庁ABR(都道府県47・市区町村1,918・町字マスタ都道府県別)
- できること: 住所文字列の分解(pref/city/lg_code/town/machiaza_id/rest をJSON出力)、町字一覧の検索
- ヘルパー: `lookup.py` が3種のマスタをキャッシュし、丁目・漢数字・郡名省略の表記ゆれを吸収して最長一致
- 注意: 番地・号の正規化とジオコーディングは対象外(デジタル庁OSS abr-geocoder を案内)。原本ホストが403のときはS3ミラーを使う
