# calil-books ガイド

カーリル図書館APIで図書館の蔵書と貸出状況を検索するスキル。無料のAPIキーが必要。

**正本は [`calil-books/SKILL.md`](../../calil-books/SKILL.md)。** キーの発行方法、検索・照会・ポーリングの手順、規約上の注意、エラー時の対応はすべてそちらを参照。

- データ: カーリル図書館API (https://calil.jp/api/dashboard/ で無料キー発行。キーは環境変数に入れ、チャットやコミットに書かない)
- できること: 「この本、近くの図書館で借りられる?」の照会(貸出可 / 貸出中 / 蔵書なし ...)
