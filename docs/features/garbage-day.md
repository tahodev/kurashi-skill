# garbage-day ガイド

5374(ゴミナシ)形式の公開CSVで、自治体のごみ収集日を地区ごとに調べるスキル。APIキー不要。

**正本は [`garbage-day/SKILL.md`](../../garbage-day/SKILL.md)。** 曜日書式(`月 木` / `月1`)の読み方、対象自治体の一覧、地区が見つからない場合の対応はすべてそちらを参照。

- データ: 各地の5374リポジトリの `data/area_days.csv` など(金沢・美唄・松前・笠間・上砂川・大分を2026-09-13に実測)
- ひとことメモ: データはボランティア保守。確実性が要る場面では自治体の公式案内を優先
- 対象自治体がなければ推測せず、自治体公式の収集カレンダーを案内する
