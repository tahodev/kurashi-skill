# bosai-alert ガイド

気象庁の防災情報(地震一覧と詳細、警報・注意報、津波情報)を公開JSONから取得するスキル。APIキー・ログイン不要。

**正本は [`bosai-alert/SKILL.md`](../../bosai-alert/SKILL.md)。** エンドポイント、詳細JSONのたどり方、空配列とエラーの区別などはすべてそちらを参照。

- データ: 気象庁 `www.jma.go.jp/bosai/` の quake / warning / tsunami JSON
- ひとことメモ: 震度の `5-` / `6+` は「5弱」「6強」と読む
- 緊急時はこのスキルの結果だけで判断せず、気象庁・自治体の公式発表を確認するよう案内する
