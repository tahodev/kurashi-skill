# air-quality ガイド

環境省の大気汚染物質広域監視システム(AEROS・そらまめくん)の測定値(速報値)を読むスキル。APIキー・ログイン不要。

**正本は [`air-quality/SKILL.md`](../../air-quality/SKILL.md)。** エンドポイント一覧、CSV/JSONの列の読み方、SPAフォールバックの罠、失敗時の対応はすべてそちらを参照。

- データ: 環境省AEROS(全国約1,600測定局、1時間値の速報値)
- できること: 全国の最新1時間値の一覧、測定局ごとの今日/7日分、都道府県ごとの月次履歴(公式JSON API)、PM2.5注意喚起エリアの確認
- ヘルパー: `lookup.py` が最新CSVを取得・キャッシュし、局名/市区町村/都道府県で絞り込んで項目上位を表示
- 注意: 速報値(確定値ではない)、緯度経度は提供されない、値は測定日時と局名つきで伝える
