# shelter-lookup ガイド

国土地理院の指定緊急避難場所・指定避難所データをダウンロードして避難所を検索するスキル。APIキー・ログイン不要。

**正本は [`shelter-lookup/SKILL.md`](../../shelter-lookup/SKILL.md)。** ダウンロードURL、CSV列の読み方、災害種別フラグ、P20(2012年度版)を使わない理由、失敗時の対応はすべてそちらを参照。

- データ: 国土地理院 避難所等データダウンロードサイト(市町村長指定の公式データ、市町村ごとの更新日つき)
- できること: 住所・施設名からの避難所検索、災害種別(洪水・津波・地震など)ごとの指定確認
