# zipcode-lookup ガイド

日本郵便の公式郵便番号データ(KEN_ALL UTF-8版)をダウンロードして、郵便番号⇄住所をローカル検索するスキル。APIキー・ログイン不要。

**正本は [`zipcode-lookup/SKILL.md`](../../zipcode-lookup/SKILL.md)。** ダウンロード手順(ページ経由必須の理由)、CSVの列構成、月次更新、失敗時の対応はすべてそちらを参照。

- データ: 日本郵便「郵便番号データダウンロード」ページのutf_ken_all.zip(月次更新)
- できること: 郵便番号→住所、住所→郵便番号、町域の一覧
