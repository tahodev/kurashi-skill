# furusato-nozei

ふるさと納税で「自己負担2,000円で済む寄附額の上限」の目安を計算するスキル。外部APIは使わず、公開されている計算式だけで求める。

## 上限額の計算式

```
上限額 = 個人住民税所得割額 × 20% ÷ (90% − 所得税率 × 1.021) + 2,000円
```

- **個人住民税所得割額**: 課税所得 × 10% で概算できる(標準税率の場合)。正確な値は住民税の決定通知書に載っている。
- **所得税率**: 課税所得(所得税ベース)に応じて下表。

| 課税所得(所得税) | 所得税率 |
| --- | --- |
| 195万円以下 | 5% |
| 195万円超 330万円以下 | 10% |
| 330万円超 695万円以下 | 20% |
| 695万円超 900万円以下 | 23% |
| 900万円超 1,800万円以下 | 33% |
| 1,800万円超 4,000万円以下 | 40% |
| 4,000万円超 | 45% |

1.021 は復興特別所得税分。

## 給与収入から課税所得を概算する

利用者が課税所得を知らない場合は、給与収入から概算する。

1. **給与所得控除** を引く:
   - 162.5万円以下: 55万円
   - 162.5万円超 180万円以下: 収入 × 40% − 10万円
   - 180万円超 360万円以下: 収入 × 30% + 8万円
   - 360万円超 660万円以下: 収入 × 20% + 44万円
   - 660万円超 850万円以下: 収入 × 10% + 110万円
   - 850万円超: 195万円
2. 給与所得 = 給与収入 − 給与所得控除
3. 課税所得 ≈ 給与所得 − 所得控除(基礎控除48万円、社会保険料控除、配偶者控除、扶養控除など)

社会保険料は給与収入の約15%で概算できる。扶養の有無で控除が変わるので、利用者に家族構成を確認する。

## 計算の進め方

1. 利用者に聞く: 給与収入(額面)、家族構成(配偶者・扶養)、わかれば課税所得や住民税所得割額。
2. 課税所得と住民税所得割額を推定し、使った前提を明示する。
3. 上限額を計算して、式と中間値を見せる。

## 目安表(総務省資料ベースのクイックリファレンス)

給与収入ごとの目安(独身または共働き、社会保険料控除のみの場合):

| 給与収入 | 上限目安 |
| --- | --- |
| 300万円 | 約28,000円 |
| 400万円 | 約42,000円 |
| 500万円 | 約61,000円 |
| 600万円 | 約77,000円 |
| 700万円 | 約108,000円 |
| 800万円 | 約129,000円 |
| 1,000万円 | 約176,000円 |

家族構成で変わる(夫婦+子2人だと同じ収入でもかなり下がる)。目安表はあくまで入口にして、必ず計算式で確認する。

## 注意(必ず伝える)

- これは**目安**。住宅ローン控除・医療費控除・株式の譲渡所得などがあると上限は変わる。
- 正確な上限は総務省や各ポータルサイトの詳細シミュレーション、または税務署・税理士に確認する。
- ワンストップ特例は寄附先が5団体以内の給与所得者向け。確定申告をする場合はワンストップは無効になり、寄附金控除として申告する。
- 上限を超えた分は自己負担になる。

## エラー・迷った時の対応

- このスキルは外部APIを使わないので通信エラーは起きない。失敗は「情報不足」「前提の不確かさ」の形で起きる。
- **情報が足りないときは推測で埋めない**: 給与収入、家族構成(配偶者・扶養)が分からないまま計算しない。利用者に聞く。
- **前提が不確かなときは明示する**: 社会保険料の約15%概算など、使った仮定を計算結果と一緒に必ず見せる。仮定を隠した数字を出さない。
- **複雑な所得がある場合は計算を降りる**: 住宅ローン控除、医療費控除、株式・副業の所得などがあると概算は崩れる。その場合は「この概算では正確に出せない」ことを伝え、総務省のシミュレーションや税務署・税理士への確認を案内する( https://www.soumu.go.jp/main_sosiki/jichi_zeisei/czaisei/czaisei_seido/furusato.html )。
- **結果は必ず「目安」と伝える**: 正確な上限額のように見せない。
