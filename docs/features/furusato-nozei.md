# furusato-nozei ガイド

ふるさと納税の寄附上限額(自己負担2,000円で済む目安)を計算するスキル。API不要の純粋計算。

**正本は [`furusato-nozei/SKILL.md`](../../furusato-nozei/SKILL.md)。** 計算式、税率表(2026年9月時点の現行値)、目安表、年収600万円の計算例、前提の明示ルールはすべてそちらを参照。

- できること: 給与収入と家族構成から上限額の目安を計算。使った前提と中間値を必ず見せる
- 制度の確認: 総務省ふるさと納税ポータル https://www.soumu.go.jp/main_sosiki/jichi_zeisei/czaisei/czaisei_seido/furusato/about/
