# gsi-geocode ガイド

国土地理院の公開API(認証不要)で、住所→緯度経度、緯度経度→標高、緯度経度→住所を引くスキル。

**正本は [`gsi-geocode/SKILL.md`](../../gsi-geocode/SKILL.md)。** エンドポイント、実測で確認した罠、失敗時の対応はすべてそちらを参照。

- データ: 国土地理院の住所検索API・標高API・逆ジオコーダ・`muni.js`(2026-10-04実測)
- できること: 住所の緯度経度化(曖昧一致の件数と前方一致の区別つき)、標高(データ元の精度つき)、緯度経度からの住所(都道府県+市区町村+町丁目)
- ヘルパー: `lookup.py`(外部パッケージ不要)
- 注意: 住所検索は関連度順ではない(「東京タワー」の本物は50件中50番目)、標高の「データなし」は文字列 `-----`、逆ジオコーダの北海道コードは先頭の0が `muni.js` と合わない
- 出典: 国土地理院
