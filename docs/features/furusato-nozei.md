# furusato-nozei ガイド

ふるさと納税の寄附上限額(自己負担2,000円で済む目安)を計算するスキル。API不要。

## 計算式

```
上限額 = 個人住民税所得割額 × 20% ÷ (90% − 所得税率 × 1.021) + 2,000円
```

所得税率の表、給与収入からの課税所得の概算手順、目安表は `furusato-nozei/SKILL.md` にまとまっている。

## 使い方の例

「年収600万円、独身です。いくらまで?」と聞かれたら:

1. 給与所得控除: 600万 × 20% + 44万 = 164万円 → 給与所得 436万円
2. 社会保険料(約15% = 90万円)と基礎控除(48万円)を引く → 課税所得 ≈ 298万円
3. 所得税率は10%(195万超330万以下)。住民税所得割 ≈ 298万 × 10% = 29.8万円
4. 上限 = 29.8万 × 20% ÷ (90% − 10% × 1.021) + 2,000 ≈ 76,700円

目安表の「600万円 → 約77,000円」と一致することを確認できる。

## つまずきポイント

- **目安であることを必ず伝える**: 住宅ローン控除や医療費控除があると上限は下がる。
- **扶養で大きく変わる**: 配偶者控除・扶養控除があると課税所得が下がり、上限も下がる。家族構成は必ず聞く。
- **制度の確認**: 総務省のふるさと納税ポータル https://www.soumu.go.jp/main_sosiki/jichi_zeisei/czaisei/czaisei_seido/furusato/about/
