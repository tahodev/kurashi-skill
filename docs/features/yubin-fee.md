# yubin-fee ガイド

日本郵便の料金を重量・サイズ・差出地から調べるスキル。料金表内蔵でネットワーク不要。

**正本は [`yubin-fee/SKILL.md`](../../yubin-fee/SKILL.md)。** 料金表の全行、区分の条件(サイズ・厚さ・重量)、オプションの組み合わせルール、対象外(ゆうメール・国際・その他のオプション)、基準日の扱いはすべてそちらを参照。

- データ: 基本料金は2024-10-01改定の現行料金(定形郵便は50g以内110円の一律料金)。オプション加算料金(速達・一般/現金/簡易書留・特定記録)とゆうパック運賃(東京発・サイズ別)は2026-09-19に公式ページで確認
- できること: 切手代の計算、サイズ・重量からの区分判定、速達書留などオプション込みの合計計算、東京発ゆうパックの運賃照会
- 注意: ゆうパックの内蔵表は東京発のみ。他の差出地は公式の料金計算ページへ誘導する。ゆうパック運賃は2026-10-01に改定予定
