# aozora ガイド

青空文庫の全作品カタログ(公式公開CSV)で作品を検索し、本文をプレーンテキストで取得するスキル。APIキー・ログイン不要。

**正本は [`aozora/SKILL.md`](../../aozora/SKILL.md)。** データソース、引数、実測で確認した罠、失敗時の対応はすべてそちらを参照。

- データ: 青空文庫 全作品一覧CSV(拡張版, 不定期更新スナップショット) + 図書カード + 本文XHTML
- できること: タイトル部分一致検索、著者名(姓名連結)での作品一覧、作品IDから本文リンク取得、本文のプレーンテキスト抽出(ルビは基底文字のみ)、カタログ件数サマリ
- ヘルパー: `lookup.py` がCSV/カード/本文をパースしてJSONで返す(外部パッケージ不要、CSVは24時間キャッシュ)
- 注意: 本文URLは作品IDから推測不可(カード取得が必須)、本文はShift_JIS、CSVはBOM付き、1作品=複数行、一覧はスナップショット(実測: 2026-08-21時点で17,840作品)。書誌はndl-books、蔵書はcalil-books
